# Лад

Уроки и практика по музыке: электрогитара, барабаны, синтезатор (3 октавы), теория, ритм и стили. Тренировки с геймификацией, Студия с инструментами. Всё работает без интернета, звук синтезируется на устройстве.

**Установка на iPhone и iPad:** откройте сайт в Safari → «Поделиться» → «На экран Домой».

**Преподаватель ИИ** — по желанию, через свой ключ Claude API в Профиле. Без ключа приложение работает полностью.

**Перенос между устройствами:** Профиль → Копия в iCloud.

## Разработка

- Исходники — ветка `main`, сборка — ветка `gh-pages`.
- Сборка: `python3 tools/make.py` (нужен Pillow) → папка `dist/` (иконки, service worker со списком файлов).
- Проверка: `cd dist && python3 -m http.server`, открыть http://localhost:8000.
